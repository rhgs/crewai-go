## How to submit

1. Read each list's CONTRIBUTING.md (each one has its own format / categories).
2. Open a PR **one at a time** — awesome-list maintainers rarely merge bundled
   submissions.
3. Use the exact title above so reviewers see you read the conventions.
4. Expect a 1–7 day wait; some lists are slow.
