# Marketing assets

Pre-written copy for external channels. None of these are auto-posted —
they’re drafts you can copy/paste.

| File | Channel |
|------|---------|
| `HACKER_NEWS.md` | Show HN (https://news.ycombinator.com/show) |
| `REDDIT_GOLANG.md` | r/golang Show & Tell |
| `TWITTER.md` | Twitter/X thread (or single tweet) |
| `DEVTO.md` | dev.to article |
| `AWESOME_LISTS.md` | PR drafts for `awesome-go`, `awesome-llm`, `awesome-agents` |

## Posting order (what gets most traction first)

1. **Hacker News** (Show HN) — biggest single spike if it hits the front page.
2. **Twitter/X** thread — quick, gets the link into circulation.
3. **r/golang** — strong, technical audience, can drive stars.
4. **awesome-go PR** — long-term discovery.
5. **dev.to** article — durable SEO, attracts slower organic traffic.

## Best days/times (US Eastern)

- HN: Tuesday or Wednesday, 8–10am.
- Twitter: weekdays 9–11am or 1–3pm.
- Reddit: weekday mornings.
- dev.to: any day, but Tuesday performs best.
- GitHub PRs to awesome-lists: any day; they’re slow either way.

## Cross-linking checklist

- Include the GitHub repo URL in every post.
- Reply to every comment within the first 2 hours.
- Pin the Twitter thread for ~24 hours.
- Cross-link the dev.to article from the README **after** the HN spike
  has died down (to avoid muddying the HN comment thread).
