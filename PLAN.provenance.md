# Plan — Provenance Model: Facts vs. Free Text

> **Status:** Draft for implementation
> **Scope:** Add a first-class Fact type populated ONLY by deterministic
> connector tools (never by the LLM), with full provenance metadata, so a
> wrong value can never be presented as a "fact the model remembered".
> Designed to plug into the guardrail feature (Gargalo 3): a provenance
> guardrail can assert that every fact has its source fields filled.

---

## 1. Goals and Constraints

### 1.1 Goals

1. Distinguish FACTS (produced by deterministic connectors/tools) from free
   text (generated by the LLM).
2. A Fact always carries provenance: source organization, source URL,
   collection timestamp, and payload hash.
3. Facts flow ONLY from tools that declare themselves as FactSource; the LLM
   can never produce a Fact.
4. Facts are collected by the executor during the ReAct loop, deduplicated
   by PayloadHash, and attached to TaskOutput and CrewOutput.
5. A helper function (`AllFactsProvenanced`) lets guardrails enforce that
   every fact has provenance fields filled.

### 1.2 Constraints (must be preserved)

| Constraint | Enforcement |
|---|---|
| Zero external dependencies | `go.mod` unchanged; Fact uses only stdlib (`time`, `crypto/sha256`, `encoding/json`, `fmt`). |
| LLM-agnostic | Facts are collected AFTER tool calls, not from LLM output. No provider dependency. |
| English comments, no accents | All godoc, error messages, identifiers. |
| Hermetic tests | `llm/mock`, spy tools, no real network. |
| Sentinel errors, context on all I/O | New sentinel `ErrNoFactSource`; context passed to all tool calls. |
| Backward compatible | Tools that do not implement FactSource produce zero facts; existing behavior unchanged. |

## 2. New API Surface

### 2.1 `Fact` struct (root package)

```go
// Fact is a piece of data produced by a deterministic connector tool, not
// by the LLM. It always carries provenance so a wrong value can never be
// presented as a "fact the model remembered".
type Fact struct {
    // Claim is the human-readable statement of the fact (e.g. "Company X
    // has CNPJ 00.000.000/0001-00").
    Claim string `json:"claim"`
    // SourceOrg is the organization that provided the data (e.g. "Receita
    // Federal").
    SourceOrg string `json:"source_org"`
    // SourceURL is the URL or identifier of the source (e.g.
    // "https://api.receita.gov.br/v1/cnpj/00000000000100").
    SourceURL string `json:"source_url"`
    // CollectedAt is when the connector collected the fact.
    CollectedAt time.Time `json:"collected_at"`
    // PayloadHash is a SHA-256 hash of the raw payload the connector
    // received, for deduplication and tamper detection.
    PayloadHash string `json:"payload_hash"`
}
```

### 2.2 `FactSource` interface (root package)

```go
// FactSource is an optional interface a Tool may implement to declare that
// it produces facts. When a tool implements FactSource, after a successful
// Call the executor collects its Facts() and attaches them to the task
// output. Tools that do not implement FactSource contribute no facts.
type FactSource interface {
    // Facts returns the facts produced by the last successful Call.
    // The executor calls this AFTER Call returns without error.
    Facts() []Fact
}
```

### 2.3 `TaskOutput` and `CrewOutput` extensions

```go
type TaskOutput struct {
    Task   string
    Agent  string
    Output string
    // Facts holds the facts collected from FactSource tools during this
    // task's execution. Populated by the executor, never by the LLM.
    Facts []Fact
}

type CrewOutput struct {
    Final      string
    TasksOutput []TaskOutput
    Duration   time.Duration
    // Facts holds all facts collected across all tasks, deduplicated by
    // PayloadHash. Populated by the executor, never by the LLM.
    Facts []Fact
}
```

### 2.4 `AllFactsProvenanced` helper

```go
// AllFactsProvenanced returns nil if every fact in the slice has
// SourceURL and PayloadHash filled. Otherwise it returns an error
// identifying the first fact missing provenance.
func AllFactsProvenanced(facts []Fact) error
```

### 2.5 `NewFact` helper (convenience)

```go
// NewFact creates a Fact with the given claim, source org, source URL, and
// raw payload. It computes the PayloadHash (SHA-256) from the raw payload
// and sets CollectedAt to the current time.
func NewFact(claim, sourceOrg, sourceURL string, rawPayload []byte) Fact
```

### 2.6 `WithFacts` option for FunctionTool

```go
// WithFacts returns a functional option that wraps a FunctionTool so it
// implements FactSource. The provided function is called after a successful
// Call to produce facts from the tool's output.
func WithFacts(fn func(ctx context.Context, output string) []Fact) func(*FunctionTool)
```

This allows declarative fact-source tools:

```go
tool := crewai.NewTool("cnpj_lookup", "...", lookupFn, crewai.WithFacts(extractFacts))
```

Wait — `NewTool` returns `*FunctionTool`, not an option-receiver. Let me
reconsider. The cleanest approach is to add a `NewFactSourceTool` constructor
that returns a tool implementing both `Tool` and `FactSource`:

```go
// NewFactSourceTool creates a tool that also implements FactSource. After
// a successful Call, factsFn is called to extract facts from the output.
func NewFactSourceTool(name, description string, fn func(ctx context.Context, input string) (string, error), factsFn func(ctx context.Context, output string) []Fact) *FactSourceTool
```

This is cleaner and doesn't change the existing `NewTool` signature.

### 3.2 Data flow

```
ReAct loop (executor.go)
  │
  ├── tool.Call(ctx, input) → result, err
  │
  ├── if err == nil:
  │     ├── observation = result
  │     └── if tool implements FactSource:
  │           facts = tool.Facts()
  │           collectedFacts = dedupFacts(collectedFacts, facts)
  │
  └── return (finalAnswer, collectedFacts, nil)

executeTask signature change:
  BEFORE: func executeTask(...) (string, error)
  AFTER:  func executeTask(...) (string, []Fact, error)

execute() in crew.go:
  result, facts, err := executeTask(...)
  → store facts in TaskOutput.Facts
  → propagate to CrewOutput.Facts (dedup across tasks)
```

### 3.3 Backward compatibility strategy

The `executeTask` signature change from `(string, error)` to
`(string, []Fact, error)` is internal — it's not part of any public API.
`Agent.Execute` calls `executeTask` and needs to be updated, but its public
signature `Execute(ctx, *Task) (string, error)` does not change.

For the structured-output path (`executeStructured`), it returns
`(string, error)` and does not use tools, so it returns `nil` for facts.
The dispatch in `executeTask` handles this.

## 4. Detailed Design

### 4.1 `fact.go`

```go
package crewai

import (
    "context"
    "crypto/sha256"
    "encoding/hex"
    "fmt"
    "time"
)

// Fact is a piece of data produced by a deterministic connector tool, not
// by the LLM. It always carries provenance.
type Fact struct {
    Claim       string    `json:"claim"`
    SourceOrg   string    `json:"source_org"`
    SourceURL   string    `json:"source_url"`
    CollectedAt time.Time `json:"collected_at"`
    PayloadHash string    `json:"payload_hash"`
}

// FactSource is an optional interface a Tool may implement.
type FactSource interface {
    Facts() []Fact
}

// FactSourceTool is a Tool that also implements FactSource.
type FactSourceTool struct {
    name        string
    description string
    fn          func(ctx context.Context, input string) (string, error)
    factsFn      func(ctx context.Context, output string) []Fact
    lastFacts   []Fact
}

// NewFactSourceTool creates a tool that implements FactSource.
func NewFactSourceTool(name, description string, fn func(ctx context.Context, input string) (string, error), factsFn func(ctx context.Context, output string) []Fact) *FactSourceTool {
    return &FactSourceTool{name: name, description: description, fn: fn, factsFn: factsFn}
}

func (t *FactSourceTool) Name() string { return t.name }
func (t *FactSourceTool) Description() string { return t.description }

func (t *FactSourceTool) Call(ctx context.Context, input string) (string, error) {
    out, err := t.fn(ctx, input)
    if err == nil && t.factsFn != nil {
        t.lastFacts = t.factsFn(ctx, out)
    } else {
        t.lastFacts = nil
    }
    return out, err
}

func (t *FactSourceTool) Facts() []Fact { return t.lastFacts }

// NewFact creates a Fact with computed PayloadHash and CollectedAt.
func NewFact(claim, sourceOrg, sourceURL string, rawPayload []byte) Fact {
    h := sha256.Sum256(rawPayload)
    return Fact{
        Claim:       claim,
        SourceOrg:   sourceOrg,
        SourceURL:   sourceURL,
        CollectedAt:  time.Now(),
        PayloadHash:  hex.EncodeToString(h[:]),
    }
}

// AllFactsProvenanced returns nil if every fact has SourceURL and
// PayloadHash filled.
func AllFactsProvenanced(facts []Fact) error {
    for i, f := range facts {
        if f.SourceURL == "" {
            return fmt.Errorf("fact %d (claim %q): missing source_url", i, f.Claim)
        }
        if f.PayloadHash == "" {
            return fmt.Errorf("fact %d (claim %q): missing payload_hash", i, f.Claim)
        }
    }
    return nil
}

// dedupFacts appends new facts to existing, skipping duplicates by
// PayloadHash (keeping the first occurrence).
func dedupFacts(existing []Fact, newFacts []Fact) []Fact {
    seen := make(map[string]bool, len(existing))
    for _, f := range existing {
        seen[f.PayloadHash] = true
    }
    for _, f := range newFacts {
        if f.PayloadHash == "" || seen[f.PayloadHash] {
            continue
        }
        seen[f.PayloadHash] = true
        existing = append(existing, f)
    }
    return existing
}
```

```

#### 4.2.3 No-tools path

```go
if len(tools) == 0 {
    out, err := a.LLM.Call(ctx, messages)
    if err != nil { return "", nil, fmt.Errorf(...) }
    return strings.TrimSpace(stripFinalAnswer(out)), nil, nil

```

#### 4.2.4 ReAct loop — collect facts after tool calls

```go
var collectedFacts []Fact

for i := 0; i < maxIter; i++ {
    // ... LLM call ...
    // ... parseFinalAnswer ...
    // ... parseAction ...

    tool, found := findTool(tools, action)
    var observation string
    if !found {
        observation = ...
    } else {
        result, err := tool.Call(ctx, input)
        if err != nil {
            observation = ...
        } else {
            observation = result
            // NEW: collect facts from FactSource tools.
            if fs, ok := tool.(FactSource); ok {
                collectedFacts = dedupFacts(collectedFacts, fs.Facts())
            }
        }
    }
    // ...
}

return "", collectedFacts, fmt.Errorf(...)
```

And on the `parseFinalAnswer` success path:
```go
if answer, ok := parseFinalAnswer(out); ok {
    return strings.TrimSpace(answer), collectedFacts, nil
}
```

And on the no-action fallback path:
```go
return strings.TrimSpace(out), collectedFacts, nil
```

(they're only collected at the Crew level).

## 5. Concurrency

- `FactSourceTool.lastFacts` is set during `Call` and read during `Facts()`.
  The ReAct loop is sequential within a task, so there's no concurrent
  access. If a tool is shared across tasks running concurrently (future),
  each task gets its own ReAct loop, but the tool's `lastFacts` could race.
  To be safe, `FactSourceTool` uses a mutex to protect `lastFacts`.

- `dedupFacts` is a pure function (creates a new map and slice); no shared
  state.

- `Task.mu` already protects task output. Facts are stored in `TaskOutput`
  (a value type, not a pointer), so no mutex needed on the facts slice
  itself.

## 6. Rules Enforcement

| Rule | How it's enforced |
|---|---|
| The LLM NEVER produces a Fact | Facts are only collected via `FactSource.Facts()` after a successful `tool.Call()`. The executor never creates facts from LLM output. |
| A task that reports a Fact MUST have collected it via a tool | The executor only collects facts in the ReAct loop after tool calls. The structured-output path returns `nil` facts. |
| Facts are deduplicated by PayloadHash | `dedupFacts` skips facts with a PayloadHash already seen. |
| Facts carry full provenance | `AllFactsProvenanced` checks SourceURL and PayloadHash. The `NewFact` helper computes PayloadHash automatically. |
| Backward compatible | Tools not implementing `FactSource` produce zero facts. `executeTask` returns `nil` for facts when no FactSource tool ran. |

| Threat | Mitigation | Test |
|---|---|---|
| **LLM injects a fact**: model outputs text claiming to be a fact | Facts only come from `FactSource.Facts()`, never from LLM output | `TestFactSource_LLMOutputNotFact` |

## 8. Example (`examples/facts/main.go`)

```go
// Facts & provenance example: a FactSource connector tool paired with a
// provenance guardrail.
//
// Run:
//
//	export OPENAI_API_KEY=sk-...
//	go run ./examples/facts
package main

import (
	"context"
	"fmt"
	"log"
	"strings"

	"github.com/rhgs/crewai-go"
	"github.com/rhgs/crewai-go/llm/openai"
)

// cnpjConnector looks up a CNPJ and returns a fact with provenance.
func cnpjConnector(_ context.Context, cnpj string) (string, error) {
	// In production, this would call the Receita Federal API.
	// Here we simulate a deterministic response.
	rawPayload := []byte(`{"cnpj":"` + cnpj + `","razao_social":"Empresa Exemplo Ltda","situacao":"ATIVA"}`)
	fact := crewai.NewFact(
		"Empresa Exemplo Ltda (CNPJ "+cnpj+") is ATIVA",
		"Receita Federal",
		"https://api.receita.gov.br/v1/cnpj/"+cnpj,
		rawPayload,
	)
	// Return the claim as the tool output (for the LLM to see).
	_ = fact // fact is collected via factsFn below
	return fact.Claim, nil
}

// extractFacts parses the tool output into a Fact slice.
func extractFacts(_ context.Context, output string) []crewai.Fact {
	// In production, this would parse the API response.
	// Here we reconstruct the fact from the claim.
	return []crewai.Fact{
		crewai.NewFact(output, "Receita Federal",
			"https://api.receita.gov.br/v1/cnpj/00000000000100",
			[]byte(output)),
	}
}

// provenanceGuardrail blocks publication if any fact lacks provenance.
func provenanceGuardrail(_ context.Context, out *crewai.CrewOutput) error {
	return crewai.AllFactsProvenanced(out.Facts)
}

func main() {
	llm := openai.New("gpt-4o-mini")

	auditor := crewai.NewAgent(
		"Auditor",
		"Audit company status",
		"You verify company registration status using the CNPJ lookup tool.",
		llm,
	)

	tool := crewai.NewFactSourceTool(
		"cnpj_lookup",
		"Looks up a CNPJ registration status. Input: the CNPJ number.",
		cnpjConnector,
		extractFacts,
	)
	auditor.WithTools(tool)

	task := crewai.NewTask(
		"Verify the registration status of CNPJ 00.000.000/0001-00.",
		"A statement about the company's registration status.",
		auditor,
	)

	crew := crewai.NewCrew([]*crewai.Agent{auditor}, []*crewai.Task{task})
	crew.Guardrails = []crewai.Guardrail{provenanceGuardrail}

	out, err := crew.Kickoff(context.Background(), nil)
	if err != nil {
		log.Fatalf("blocked: %v", err)
	}

	fmt.Println("\n=== Result ===")
	fmt.Println(out.Final)
	fmt.Printf("\n=== Facts (%d) ===\n", len(out.Facts))
	for _, f := range out.Facts {
		fmt.Printf("- %s (source: %s, hash: %s)\n", f.Claim, f.SourceURL, f.PayloadHash)
	}
}
```

### 9.1 `docs/tools.md` — new "Facts & provenance" section

```markdown
## Facts & provenance

A **Fact** is a piece of data produced by a deterministic connector tool, not
by the LLM. It always carries provenance (source organization, source URL,
collection time, payload hash) so a wrong value can never be presented as a
"fact the model remembered".

### The Fact type

```go
type Fact struct {
    Claim       string    `json:"claim"`
    SourceOrg   string    `json:"source_org"`
    SourceURL   string    `json:"source_url"`
    CollectedAt time.Time `json:"collected_at"`
    PayloadHash string    `json:"payload_hash"`
}
```

### Making a tool a FactSource

A tool declares itself as a fact source by implementing the `FactSource`
interface or by using `NewFactSourceTool`:

```go
tool := crewai.NewFactSourceTool(
    "cnpj_lookup",
    "Looks up CNPJ status. Input: the CNPJ number.",
    func(_ context.Context, cnpj string) (string, error) {
        // call your API...
        return "Company X is ATIVA", nil
    },
    func(_ context.Context, output string) []crewai.Fact {
        return []crewai.Fact{
            crewai.NewFact(output, "Receita Federal",
                "https://api.receita.gov.br/...", []byte(rawPayload)),
        }
    },
)
```

After each successful `Call`, the executor collects the tool's `Facts()` and
attaches them to `TaskOutput.Facts` and `CrewOutput.Facts`.

### Rules

- The LLM NEVER produces a Fact. Facts come only from FactSource tools.
- Facts are deduplicated by PayloadHash (first occurrence kept).
- Tools not implementing FactSource contribute zero facts.

### Provenance guardrails

Use `AllFactsProvenanced` in a guardrail to enforce that every fact has
SourceURL and PayloadHash:

```go
crew.Guardrails = []crewai.Guardrail{
    func(_ context.Context, out *crewai.CrewOutput) error {
        return crewai.AllFactsProvenanced(out.Facts)
    },
}
```

If any fact lacks provenance, `Kickoff` returns `ErrBlockedByGuardrail`.

## 11. Edge Cases and Decisions

| Case | Decision |
|---|---|
| FactSourceTool shared across concurrent tasks | Mutex on `lastFacts` to prevent race. |
| Tool returns error | `Facts()` returns nil; no facts collected. |
| `factsFn` is nil | `Facts()` returns nil after successful call. |
| Fact with empty PayloadHash | Skipped by `dedupFacts` (not added). |
| Same fact from two tools (same PayloadHash) | First occurrence kept; second skipped. |
| Structured task (no tools) | Facts is nil; structured output works normally. |
| No FactSource tools in crew | `CrewOutput.Facts` is nil; existing behavior unchanged. |
| Guardrail accesses `out.Facts` | Works: `Facts` is a field on `CrewOutput`; nil if no facts. |
| `AllFactsProvenanced(nil)` | Returns nil (no facts to check). |
| `AllFactsProvenanced([]Fact{})` | Returns nil (empty slice). |
